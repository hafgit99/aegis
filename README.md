Aegis Vault is an offline-first, portable, and ultra-secure password manager designed for serious security needs. Built with **Electron**, it runs locally on your machine without relying on any cloud servers, ensuring true Zero-Knowledge privacy.

## 🛡️ Core Security Features

- **Zero-Knowledge Architecture**: Your data never leaves your device. We cannot see your passwords even if we wanted to.
- **AES-256-GCM Encryption**: Military-grade encryption is used for all sensitive data.
- **Argon2id Key Derivation**: Protected against brute-force attacks with the modern standard for password hashing.
- **Biometric Integration**: Seamlessly unlock your vault using Windows Hello or TouchID, secured via OS-level Keytar storage.
- **Encrypted Audit Logs**: Every action is logged into an encrypted, tamper-evident local audit file.
- **Memory Protection**: Sensitive data is cleared from memory when the vault is locked.

## 🚀 Key Capabilities

- **Portable Mode**: Run directly from a USB stick without installation.
- **3D Card View**: Visualize your credit cards with a flip animation to see CVC and details securely.
- **Secure File Storage**: Store sensitive files and documents encrypted alongside your passwords.
- **Offline-First**: No internet connection required. Your vault is always accessible.
- **Breach Monitoring**: (Pro Feature) Local analysis of password strength and reuse.
